
# 自化与视同自化识别 + 时间应数

## R · 出处与方法根基

> f05（A02 四化象）：
> "宫干使该星在自己宫位质变称自化；在他对面的宫位质变称视同自化……四化象是这门紫微斗数命理学的用神，自化象和视同自化象是用神中的用神……自化的重心在时间的观念，故其解释重心在大运的宫位、或流年宫位。"

自化与视同自化皆属于「用」——代表后天变数、今生造化（体用之分见 p09：生年四化为体／飞宫与自化为用）。它们比飞宫四化更进一层：飞宫是从某宫左下方宫干"飞出去"看它宫，自化则是该宫宫干使"本就在本宫或对宫的那颗星"发生质变，是更直接、更内在的"用神中的用神"。其解释重心不在象义本身，而在"时间观念"——变化发生于何大运、何流年（应数）。

## I · 操作心法

判读任一宫职的自化，按以下要点：

1. **定位宫干所化之星**：看某宫（以该宫立太极）的宫干，依十天干四化曜表，找出它使哪颗星发生"质变"（化禄/权/科/忌）。
2. **判落本宫 → 自化**：若该星正好就在这同一宫位（宫干使本宫之星质变），称"自化"——变数由自身发起，属自我造化。
3. **判落对宫 → 视同自化**：若该星被该宫干化出后落在"对面宫位"（如夫妻宫干使贪狼化忌、贪狼恰在迁移宫），称"视同自化"——含"不断缘起、历史重演"之意。
4. **二者皆象之用，代表今生造化**：不同于生年四化（先天定数、此生格局），自化/视同自化是"今生今世的造化"，是运的走势中真正发动的变数。
5. **重心在"时间观念"**：自化的解释不求象义本身，而求"变化发生于何大运、何流年"（应数）；定位到对应的大运宫位或流年宫位，才算读完。
6. **自化高于飞宫**：自化与视同自化是"用神中的用神"，断应期时其时间应数优先于普通飞宫；飞宫不可独占应期判断（避 ce09）。

一句话：宫干使某星质变——落本宫即自化、落对宫即视同自化；二者皆是今生造化，解释重心在大运/流年的时间应数，自化高于飞宫。

## A1 · 书中示范（命宫桃花星自化忌 · 桃花收束 · c09）

- **问题**：命宫满是桃花星（廉贞、贪狼、天姚、文昌），如何读这辈子的桃花走势？
- **用法（识别自化 + 转折）**：此盘命宫宫干为「癸」干，癸使贪狼化忌；而贪狼星正好就在命宫本宫——即"贪狼在自己宫位质变"，这正是**自化忌**。命宫本是桃花渊薮，却因自化忌而"桃花收束"：虽有极深异性缘，却懂得分寸、拒绝诱惑，不愿陷于绯闻循环。
  > c09 原引："命宫里面都是桃花星，代表这一辈子的我非常有桃花……但是它的宫干是癸……贪狼正好在自己宫位，我们称为自化忌。代表它桃花收束了。"
- **结论**：本例展示自化作为"用神中的用神"对先天象的转折——先天（生年/本宫星）只给"命带大桃花"，自化忌才定出"今生清清闲闲、桃花收束"的造化。后续若断此桃花收束"发动于何年"，须看大运/流年走到引动该自化忌的宫位（时间应数）。

## A2 · 适用情境与识别信号

**情境**：
- 想弄清"自化是什么""什么是视同自化"，区分它与飞宫、生年四化。
- 要定"时间应数"——某变化（婚动、破财、桃花收束、缘起缘灭）发生于哪一大运、哪一流年。
- 用户直接问"变化发生在哪一年""怎么看今生造化/缘起""不断缘起、历史重演怎么读"。

**信号（命中本 skill 的问法）**：
- "自化""视同自化""自化忌/自化禄"
- "应数""时间观念""变化在哪一年/哪一运"
- "今生造化""缘起""历史重演"

**与相邻 skill 的区分**：
- 本 skill 读**用神中的用神**（自化/视同自化）与其**时间应数**（大运/流年），是四化中最内在、最优先的时间层。
- `qintian-sihua-flying` 读**普通飞宫动态**（宫干飞出去看它宫，运的走势），是"用"但不是"用神中的用神"；断应期时二者必须合参，自化高于飞宫。
- `qintian-sihua-natal` 读**静态体象**（生年四化 = 先天定数、此生格局），不涉及今生造化与应数时间。
- 三者都建立在 `qintian-sihua-trinity`（宫象星三合一）之上——先立太极、先宫象合一，再谈自化与飞化。

## E · 执行步骤与完成标准

**步骤**：
1. **看某宫宫干所化之星**：以所研究宫职立太极，取该宫宫干，依十天干四化曜表找出它使哪颗星质变（禄/权/科/忌）。
2. **判落本宫（自化）或对宫（视同自化）**：若该星落在同一宫 → 自化；若落在对面宫 → 视同自化。明确写出"X 宫干使 Y 星化 Z，落本宫/对宫=自化/视同自化"。
3. **定位变化的时间应数（大运/流年宫）**：把自化落点放回大运盘与流年盘，找出引动该自化的大运宫位与流年宫位，定出变化发动的时间（应数）。
4. **得今生造化结论**：综合自化/视同自化义（造化、不断缘起/历史重演）+ 时间应数，给出"何运何年发生何造化"的完整结论，并与生年体象、飞宫动态合参。

**完成标准（每条可核验）**：
- [ ] 已写明研究宫职、其宫干、所化之星与化象，且未与"左下方宫干飞出"的飞宫混淆。
- [ ] 已正确判定"本宫=自化 / 对宫=视同自化"，未错判为飞宫或生年。
- [ ] 已给出时间应数——定位到具体大运宫位与流年宫位，而非只停于象义描述。
- [ ] 已用"用神中的用神"立场，指出自化高于飞宫，并在断应期时与飞宫合参（避 ce09）。
- [ ] 结论已与生年体象（qintian-sihua-natal）对照，区分"先天格局"与"今生造化"。

## B · 边界与反模式

**反场景（本 skill 不适用）**：
- 仅需看"先天格"——只想定此生富贵贫贱之格、不关心今生造化与应数时间时，用 `qintian-sihua-natal` 读生年四化即可，不必谈自化。
- 纯排盘/只列星曜庙旺不谈四化——属 ce08（重星轻象），不在本 skill 范围。

**书中明确警告（ce09 · 分不清自化与飞宫、只用飞宫断时间忽略自化应数）**：
> "自化象和视同自化象都是象之用……自化的重心在时间的观念，故其解释重心在大运的宫位、或流年宫位。……自化象和视同自化象是用神中的用神。"

失败模式：只从宫干飞宫四化找"哪年哪月发生"，忽略自化/视同自化才是"用神中的用神"、其解释重心在大运/流年应数，致**应期错判或漏读真正发动的变数**。机制是把飞宫（动态认识、运的走势）与自化（用神中的用神、今生造化、时间应数）混为一谈。

**作者立场盲点**：
- 作者为本派传人，把自化抬到"用神中的用神"高于飞宫，并贬低他派（称坊间书"东拼西凑、以讹传讹"），未正面比较三合派/飞星派差异，存在学派自抬盲区。
- 飞宫学"八大原则"（A08–A09）原文对应页为空页未读到，本 skill 只取 A02 对自化/视同自化的明确定义，不杜撰缺失细则。

**元边界（诚实声明）**：
- 本书属传统术数/玄学体系，源于古代术数，**未经现代科学实证**。其"天干气化飞渡使星辰质变""物物一太极"属前现代宇宙观。
- 四化垂象与人生吉凶之间缺乏可重复、可证伪的经验证据；"同盘不同命"难在本体系内圆融解释；解象主观诠释空间大，易落巴纳姆效应与确认偏差。
- 最稳妥立场：将其视为一套**文化性象征解释系统**与**人生命运的反思框架**，不宜作为婚姻、创业、健康等重大决策的**唯一**依据。
