
# 星辰研究法（物物一太极 · 阴阳五行 · 双星碰撞 · 落宫分组）

## R — 来源原则（Root）

> f13 原文引述（B01 星辰研究的方法）：
> 「每一颗星辰的研究，须先将该星辰就视同一太极。既是太极必有其阴阳五行，因此就该星辰的阴阳五行推理出单星的特质。由单星的特质，兼论婚姻桃花、疾厄症状、事物行业。」

核心立场：**星是「导气」于宫象之间的介质，不是吉凶的主判**。每颗星都可被当作一个独立太极，从其阴阳五行推演出特质，再落到婚姻、疾厄、行业等范畴——这是区别于「只背星义 / 只论庙旺」的研究法。

## I — 方法（Instruction）

研究任意单颗星曜，依以下五步通用流程推演（区别于死背星义）：

① **每颗星视同一太极**——把目标星当作一个独立太极，不依附于命宫或其他宫的中心。
② **按阴阳五行推理单星特质**——由该星的阴阳属性、五行属性推其基本特性（如紫微己土居中统帅、武曲辛金性刚、太阴癸水属阴主女性）。
③ **兼论婚姻桃花 / 疾厄 / 事物行业**——由单星特质延伸到：婚姻桃花象、疾厄症状、事物行业与适读学系。
④ **看双星碰撞**——考察该星与同宫或对宫他星的互动（同宫或对照），碰撞后产生的新特质会修正单星本义。
⑤ **看落宫地支分组**——按落宫地支归组，决定其伴随星：
   - **子午卯酉（四正）**：受贪狼 / 巨门 / 天梁等影响；
   - **辰戌丑未（四墓）**：受破军、天相等影响；
   - **寅申巳亥（四马）**：受天府、七杀等影响，主驿马。
   由分组找出同宫 / 对宫的伴随星，以双星碰撞论定该落点的个性、行业、格局。

## A1 — 书中应用（Application · 案例）

**案例一：紫微在子午——受贪狼影响（落宫分组 + 双星碰撞）**
- **问题**：紫微星在子宫或午宫坐命，如何定此落点的格局？
- **用法**：第⑤步落宫分组——子午属「四正」，紫微在此受贪狼影响；第④步双星碰撞——紫微（帝王、统帅）＋贪狼（桃花、才艺、佞臣）碰撞，成「帝王傍佞臣」之局，主桃花、才艺、耳软心活。
- **结论**：此落点不可单看紫微「帝王之尊」，须参贪狼特质——个性带桃花、耳软、善才艺；论断时以双星碰撞义而非单星本义为准。

**案例二：武曲贪狼（武贪格）——不发少年人（双星碰撞 + 作者断语）**
- **问题**：武曲贪狼同宫（丑未，武贪格），早年横发之财能否守成？
- **用法**：第②步单星特质（武曲辛金性刚、将星；贪狼桃花主）+ 第④步双星碰撞（武贪组合）。引 p34：「武曲贪狼不发少年人，早发必破，中晚年为佳……横发之财，则横发之后需部分回馈社会……否则会影响福泽、损及寿元。」
- **结论**：武贪不发少年人，早发必破，中晚年方佳；横发之财须部分回馈社会（孤儿院、慈济等），否则损福泽、损寿元。走己运横发仅发三年宜守。

## A2 — 触发与信号（Activation）

**适用情境**
- 解读某颗星曜（太阴、武曲、天同、廉贞、巨门、贪狼、天相、天魁钺、天刑、禄存、羊陀、红鸾、左右等）的本义与落点。
- 研究单星的系统方法 / 用阴阳五行推星性。
- 双星碰撞（同宫或对照互动）的格局判定。
- 落宫地支分组（四正 / 四墓 / 四马）决定伴随星。

**触发信号**
- 「某星怎么解」「怎么研究单星」「双星碰撞」「落宫分组」「阴阳五行推星性」「某星落某宫」。

**与其他 skill 的区分**
- 本 skill 是「研究星的方法 + 单星知识库」，对象是星曜本身。
- `qintian-sihua-trinity`（宫象星三合一总纲）是总纲——星须先宫象合一再配星，不可本末倒置（见 ce08 重星轻象）。
- 只问四化象（禄权科忌、生年 / 飞宫 / 自化、双象组合）读法时，**不调用本 skill**，交给对应读象 skill；本 skill 仅在「配星导气」环节接入。

## E — 执行清单（Execution · 完成标准）

研究一颗星时，逐条完成并确认：

1. **取目标星视同一太极**——明确将该星独立为分析中心，不预设以命宫为本义。（完成标准：已指明该星及其落宫，未与命宫本义混淆。）
2. **按阴阳五行推特质**——给出该星阴阳、五行属性，并推演出 1–3 条单星基本特质。（完成标准：特质由阴阳五行逻辑导出，非凭空断语。）
3. **兼论婚姻 / 疾厄 / 行业**——至少延伸该星在婚姻桃花、疾厄症状、事物行业三范畴之一的含义。（完成标准：已给出可落盘的具体范畴解释。）
4. **查双星碰撞与落宫地支分组得伴随星**——列出同宫 / 对宫互动星，并按子午卯酉 / 辰戌丑未 / 寅申巳亥定伴随星。（完成标准：已说明碰撞后修正义，且地支分组与伴随星对应正确。）
5. **综合得该星此落点格局**——结合以上四步，给出该星在此落点的个性 / 行业 / 格局结论。（完成标准：结论为「单星特质 + 碰撞修正 + 落宫分组」三者综合，而非单面星义。）

## B — 边界与警示（Boundary）

**反场景（不调用）**
- 纯四化象问题（只问禄权科忌、生年 / 飞宫 / 自化、双象组合）不调用本 skill，交读象 skill。
- 未先宫象合一、直接以星曜庙旺断吉凶（ce08 重星轻象）属误用——须先宫象合一再配星。

**书中明确警告（不可无条件断凶）**
- **ce06 武曲女命**：武曲称「寡宿之星」，**唯须逢化忌或煞星才算**；入女命命宫不利配偶、主缘薄或刑克。不可一见武曲坐女命即断克夫，且后天修身「以柔克刚」可婚姻幸福可期。
- **ce11 天同男命**：天同坐男命易懒散，但**若命宫逢化权或化忌即能冲动懒散、反有开创事业之局**（水澄桂萼格同论）。不可断「懒散一生无事业」。
- **ce14 廉贞官非**：廉贞化忌（或廉贞坐命）**须「大运官禄宫廉贞化忌冲本命或官禄宫」才触发**官非牢狱；且须与文昌 / 文曲化忌、天刑等官非星合参。不可一见廉贞化忌即断必坐牢。

**作者盲点（来自 BOOK_OVERVIEW 批判）**
- 作者为该流派传人、书末自署「理事长」，立场鲜明，把四化象抬为灵魂、贬低他派，未正面比较三合派 / 飞星派方法论优劣，存在「学派自抬」盲区。
- 将现代职业（金融机构、直销、网络等）套入星曜「事物行业论」，显系后世附会增补；以「物理学质能转化」类比「天干气化飞渡」为现代借喻，非实证依据。

**元边界（诚实声明）**
- 传统命理 / 玄学体系，源流为古代术数，**未经现代科学实证**。最强反对意见：四化垂象与人生吉凶间缺乏可重复、可证伪的经验证据；「同盘不同命」难在本体系内圆融解释；解象主观诠释空间大，易落巴纳姆效应与确认偏差。
- 最稳妥立场：视为**文化性象征解释系统**与**人生反思框架**，不宜作为婚姻、创业、健康等重大决策的**唯一**依据。

## 单星论速查 参考

> 以下为 p32–p49 单星论主要规则的知识库（作为 A3 / 落盘参考），**触发条件与反例一律以本文件 B 段为准**，不可脱离四化象与前提直接套用。

- **太阴（p32）**：女性星，坐命宜女不宜男；男命有夺妻宿之嫌、较不利太太。
- **武曲（p33）**：将星性刚，坐命宜男不宜女；女命**须逢化忌或煞星（寡宿发动）**方主缘薄刑克（见 ce06）。
- **武贪（p34）**：武曲贪狼不发少年人，早发必破，中晚年方佳；横发之财须部分回馈社会，否则损福泽寿元。
- **天同（p35）**：福德主，坐命宜女不宜男；男命**须逢化权或化忌**方有开创局（见 ce11）；天同化忌易偏激误入歧途（水澄桂萼格除外）。
- **天同巨门（p36）**：先劳碌是非而后有福；从事教职 / 大众传播 / 民意代表 / 饮食业可平衡巨门之缺憾。
- **廉贞官非（p37）**：大运官禄宫廉贞化忌**冲本命或官禄宫**防官非牢狱（见 ce14）；文昌 / 文曲 / 巨门化忌或天刑中主星化忌亦属官非星。
- **廉贞七杀（p38）**：路旁埋尸格，逢化忌或煞星且落本命 / 本迁 / 大命 / 大迁，防交通意外劫数。
- **天相（p39）**：专解廉贞之恶的官禄主；与廉贞同宫**不逢化忌**则廉贞不以囚星解。
- **天相未宫（p40）**：不喜在未宫又逢左右 / 昌曲，且为命宫或夫妻宫时，主先天姻缘不美。
- **巨门（p41）**：口舌是非星，善用口才（教师 / 律师 / 调解）为「可是之人」，否则祸从口出成「可非之人」。
- **贪狼（p42）**：桃花主，坐命无论男女皆宜晚婚，配偶年龄差五岁以上为佳；守命不宜女命。
- **天魁钺（p43）**：天魁阳贵（白天生人得男贵）、天钺阴贵（晚上生人得女贵）；四十岁前得人荫、四十岁后反主荫人。
- **天刑（p44）**：不宜入六亲宫，表征与该亲人生观 / 价值观有差距、话不投机；**非「同床异梦」**（纠正坊间以讹传讹，见 ce03）。
- **禄马交驰（p45）**：天马与禄存同宫于财帛宫，财在远乡求、外出发迹之命。
- **红鸾天喜（p46）**：喜庆之星，**非「红鸾星动」必提亲论嫁**；婚姻和合不据此星论断（见 ce07）。
- **左右弼（p47）**：入命 / 夫妻宫**非必二度姻缘**，实为婚前感情困扰（三角 / 死角）；纠正古书食古不化（见 ce04）。
- **羊陀（p48）**：羊刃（命）＋陀罗（夫）婚姻波折重，唯「忍」字可减轻冲击（大运走到同论）。
- **禄存（p49）**：有解厄制化之功（可制化巨门之恶、解厄延寿）；宜入命 / 财帛 / 田宅主有财；坐命主有财有寿唯精神孤。
