# 钦天四化 术语表（共享概念词典）

来源：《钦天四化紫微斗数基础》许铨仁。下列定义尽量采用作者原文，并标注与常识/他派的关键差异——差异部分最值钱，它决定本派读法与他人不同。

## 一、核心框架

### 十二宫 / 宫位
十二宫：命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友(奴仆)、官禄、田宅、福德、父母。每宫有「基本含义 + 隐藏性含义」。
关键差异：作者强调「任何宫皆可立太极」且「宫职有隐藏性含义」（如财帛宫是夫妻宫的夫妻位，婚后对待须参合财帛宫）。

### 宫象星三合一
「首重在宫象合一，便呈现吉凶；而后再配星。」这是全体系解译次第。
关键差异：≠ 三合派「重星曜庙旺」。作者把「象(四化)」抬到高于星曜的地位，星仅「导气于何方」。先宫象合一定吉凶，再配星；先摆星曜庙旺会本末倒置。

### 四化象（用神 / 灵魂）
化禄、化权、化科、化忌合称四化象，「天垂象示吉凶」之象，由天干「气化飞渡」使星辰质变而成（一干生四象）。
关键差异：≠ 「星曜庙旺决定吉凶」。四化象是全体系的用神/灵魂。

## 二、四化象分论

### 化禄
福报良性循环、人缘桃花、具解厄制化之功、与健康寿元有关。生年禄 + 生年科入命迁父疾 = 长寿格。

### 化权
正面 = 开创/掌权/专技；负面 = 任性霸道、争执摩擦。疾厄 = 自我意识强爱现；夫妻 = 一山不容二虎。

### 化科
科名功名、声名、念旧、贵人、解厄制化、良性桃花（重情调）。是长寿格要件之一。

### 化忌（最易被误读）
≠ 坊间「见忌如见鬼 / 化忌 = 大凶」。作者用法：在财帛飞忌「入六内宫」主收藏得财（冬藏解）；在六亲宫主「潜意识亏欠感」；在人位忌入人位 = 管束。须依所落人事物宫位分别解释。命理学是平衡学，平衡化忌即顺势而为。

## 三、体用与动态

### 生年四化（体）
依出生年干垂象，代表先天定数，决定此生富贵贫贱之格，关联「来因」（来也盛年，归也生年）。

### 飞宫四化（用）
从「所研究宫职左下方宫干」飞出四化做「动态认识」，揭示后天变数/运之走势，是断「何年何月发生」的关键。静(本宫) + 动(飞宫)须合参。

### 自化 / 视同自化（用神中的用神）
宫干使某星质变：落本宫 = 自化；落对宫 = 视同自化。二者重心都在「时间应数」（大运/流年），地位高于飞宫，代表今生造化。视同自化额外含「不断缘起、历史重演」。

### 体用
生年四化 = 体（先天定数/格）；飞宫与自化 = 用（后天变数/运）。静动合参方完整。

## 四、立太极与落宫规则

### 立太极 / 中太极
「物物一太极」：命盘是大太极，内含十二小太极，任何宫都可立为分析中心。两宫合参（如命+兄）称「中太极」，使该宫之象与命宫发生关系。

### 象依宫解 / 六亲宫视同命宫解
象落何宫即受该宫范围。六亲宫（命兄夫子友父）须「视同命宫」解释（把「我有禄」更替为「我的某六亲有禄」）。

### 六内宫 / 六外宫
财官得失的分组判准：化忌入六内 = 收藏得财(吉)，入六外 = 破财(凶)。注意：本书作为已知前提反复使用，但未明确列出哪六宫为内/外，使用时须依用户所用排盘体系补全（常见以「命、财、疾、官、田、福」为六内，其余六外；若用户体系不同，务必先确认）。

### 宫职隐藏性含义 / 配宫
每宫除基本义外有隐藏义，且宫与宫有配宫关系（夫妻配财帛看婚后对待；子女=合伙/桃花/意外宫等）。操作：列基本义 + 隐藏义 → 找配宫 → 合参。

## 五、星曜（研究法 + 关键星）

### 物物一太极 / 双星碰撞（星研究法）
每星视同一太极，按其阴阳五行推理单星特质，再兼论婚姻/疾厄/行业；看双星碰撞（同宫/对宫互动）得新特质。

### 禄存
「财王」+ 解厄制化/延寿，但亦主孤寡。与巨门同宫可制巨门之恶。

### 羊陀（羊刃 / 陀罗）
羊刃 = 阳金、刑伤血光；陀罗 = 阴金、相当于一颗「化忌星」、原地打转挥之不去的不顺。

### 红鸾 / 天喜
喜庆之星，但 ≠「红鸾星动必婚/必提亲」。婚姻和合论断应依四化象落夫妻宫，而非红鸾。

### 天刑
入六亲宫 = 与该亲人生观/价值观有差距、话不投机，≠ 坊间「同床异梦」。亦是借贷/官非/医药星。
