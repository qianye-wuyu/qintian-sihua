
# 读生年四化（体）

## R — 原文依据（source_quote, f03）

> 「依据出生年垂象出来的化禄、化权、化科、化忌就是你的生年四化象……先天定数代表命的本质论，决定了一个人此生富贵贫贱之格。代表个人的先天定数，象之体。」

（来源：A02 四化象的类型㈠生年四化象→体）

## I — 本技能要义（用自己的话）

生年四化是钦天四化体系里的「体」——依出生年干查十天干四化曜表，得到该年四颗四化星（如戊申年：贪狼禄、太阴权、右弼科、天机忌），即为命盘与生俱来的先天定数。
它定此生富贵贫贱之格，是静态的、与生俱来的命的本质，不与后天运程混谈。
它与两性缘、姻缘类型相关，书中以「来也盛年，归也生年」点出：此生男女关系聚散，也可从生年四化的落宫窥其形态。
读生年四化的目的，是先立住「格局之体」，再与飞宫（用）、自化（用）对照，才完成先天定数与后天变数的合参。
本技能只管静态的「体」，不涉动态运程与应期。

## A1 — 书中应用案例（c03 戊申年生四化例）

**问题**：有一人是「戊申年」生，如何定其生年四化与先天格？
**用法**：①取出生年干「戊」；②查上表戊干一行→贪狼化禄、太阴化权、右弼化科、天机化忌；③四星落宫即为生年四化象（体）。
**结论**：贪狼禄、太阴权、右弼科、天机忌即此人的生年四化象，属先天定数、象之体，决定其一生的富贵贫贱之格；并引出「来也盛年，归也生年」的姻缘观——其两性缘类型可从四化落宫推断。

## A2 — 触发情境 / 识别信号 / 技能区分

**情境**
- 用户给出出生年干，问「我的生年四化是什么 / 戊申年四化怎么排」。
- 用户问「我的先天格局如何定 / 怎么看此生富贵贫贱之格」。
- 用户问「来因」「我为何而来」「我的姻缘类型」相关（生年四化主来因与两性缘）。

**识别信号（用户原话）**
- 「我的生年四化」「戊申年四化」「先天格」「来因」「我的四化是什么」。

**技能区分（避免错用）**
- 本技能 `qintian-sihua-natal`：读**静态体象**（出生年干 → 四化星），定先天定数。
- `qintian-sihua-flying`（体 vs 用）：读**动态飞宫用象**（从宫职左下方宫干飞四化），断运的走势与应期——用户问「何年何月发生」时用它。
- `qintian-sihua-self-transform`：读**自化 / 视同自化**（象之用、用神中的用神），定今生造化与时间应数。

## E — 执行步骤（附完成标准）

1. **取出生年干**：确认用户提供的生年天干（甲/乙/丙/丁/戊/己/庚/辛/壬/癸）。
   - 完成标准：已锁定一个明确天干，无歧义。
2. **查十干四化曜表**：依该干取化禄、化权、化科、化忌四星。
   - 完成标准：四星全部从表中取出，且与天干一一对应正确。
3. **定生年四化象（体）**：将四星对应到命盘所落宫位，即为生年四化象；它是静态的先天定数，决定此生富贵贫贱之格。
   - 完成标准：已说明「这是体、先天定数」，并点出可关联姻缘类型（来因观）。
4. **与飞宫 / 自化对照**：把生年四化作为「体」，留待与飞宫（用）、自化（用）合参，不在此步展开动态运程。
   - 完成标准：明确标注本步骤仅立「体」，动态部分移交 flying / self-transform 技能。

## B — 边界与诚实声明

**反场景（不应使用本技能）**
- 用户仅需排盘、不知出生年干 → 无法取四化，先补全年干。
- 用户问飞宫动态运程、何年何月发生 → 用 `qintian-sihua-flying`。
- 纯娱乐调侃、不涉论断 → 可简述，但不做宿命结论。

**书中警告（诚实标注）**
- 飞宫学「八大原则」原文在转换文本中对应页（约第17–21页）为空页，**内容缺失**；本技能不涉及飞宫，故不杜撰其条文，相关动态读法以 `qintian-sihua-flying` 的总纲为准。
- 十干四化曜表：本书原文仅明示甲/戊/壬/癸四干示例，乙/丙/丁/己/庚/辛依作者所引「标准十干四化曜」补全，非本书逐字列出；如与原书版本有异，须向原始 PDF 复核。

**作者盲点**
- 本书为钦天四化流派口述讲义，立场鲜明，把四化象抬为「用神」并贬低他派读法；论断「同盘不同命」等反例本书未处理，读者宜知体系边界。

**元边界（重要）**
- 传统命理属文化性象征解释系统，未经验证、不可证伪；生年四化仅作人生反思框架，**不作婚姻、创业、健康等重大决策的唯一依据**。
