
# 来因观与夫妻宫姻缘形态

## R（理论依据 · Reference）

> 来源 f16 / A02 四化象：
> "来也盛年，归也生年。两性关系逃不开二十个字：缘尽情未了，情尽缘未了，缘情皆未了，缘情皆了了。为什么还要做人？目的十六个字：恩怨情仇、悲欢离合、喜怒哀乐、生老病死。"

生年四化既是"体"（先天定数、定富贵贫贱之格），也主此生男女两性缘的聚散类型——"来也盛年，归也生年"点出人"何以来此生"与姻缘的勾连。

## I（解释框架 · Interpretation）

把生年四化与"人何以来此生"勾连的判断框架：

1. **生年四化定格亦主缘**：生年四化（依出生年干取，见 qintian-sihua-natal）既定富贵贫贱之格，也主两性缘的聚散类型。
2. **缘情二十字诀**（聚散四态）：
   - 缘尽情未了　/　情尽缘未了　/　缘情皆未了　/　缘情皆了了
3. **目的十六字诀**（人生课题）：恩怨情仇、悲欢离合、喜怒哀乐、生老病死——把姻缘纳入"来还恩怨情仇"的叙事框架。
4. **夫妻宫四化定姻缘形态**（象依宫解，六亲视同命宫）：
   - **禄**在夫妻 → 自由恋爱、感情早发（早发未必早婚）。
   - **权**在夫妻 → 婚姻多奉父母之命或儿女之缘促成。
   - **科**在夫妻 → 经人介绍、媒介认识而成。
   - **忌**在夫妻 → 缘薄，宜晚婚；初恋不宜结合，第二、三、五个对象才是真正配偶（p25）。

## A1（书中应用 · 一个实例）

**问题**：命盘夫妻宫见生年化忌，当事人问"我是不是姻缘不好、这辈子要孤寡？初恋能不能成？"

**用法**（套本技能 I 框架）：
- 查生年四化落夫妻宫＝化忌 → 属"缘薄"形态（f16 / p25）。
- 套缘情诀：夫妻宫化忌多为"缘情皆未了"或"缘尽"型，初恋属第一段，忌在夫妻主初恋不宜结合、早婚易生离。
- 据 p25：真正配偶往往是第二、三、五个对象，晚婚反主吉。

**结论**：夫妻宫化忌≠孤寡凶格，而是"缘薄宜晚婚"。建议不急于初恋结合、宜晚婚，把早段关系视为成长课题；把红灯当常态修炼（心有傲数之功），而非宿命绝断。

> 补充（p42）：贪狼坐命无论男女皆以晚婚为吉，配偶年龄相差五岁以上为宜——与夫妻宫化忌的"晚婚主吉"方向一致，可互为参证。

## A2（触发情境与区分 · Application）

**情境**：问"我姻缘是什么形态 / 夫妻宫化忌要不要紧 / 为什么我晚婚 / 初恋能不能成 / 我是缘薄吗"。

**信号词**：姻缘形态、夫妻宫化忌、为什么晚婚、初恋能不能成、缘薄、缘情诀、来因。

**技能区分**：
- 本技能 → 解**夫妻宫姻缘类型与早/晚婚倾向**（生年四化 + 夫妻宫四化 + 缘情诀）。
- `qintian-sihua-dual-symbol` → 解**双象二度姻缘**的精细区分（如禄权＝二度姻缘、权忌＝婚后谈恋爱等），不在本技能范围。
- `qintian-sihua-hua-ji` → 解**化忌一般义**（收藏/管束/亏欠/六内六外等），不讲姻缘形态。
- `qintian-sihua-natal` / `qintian-sihua-trinity` → 取生年四化、宫象星合一时先调用，本技能在其之上叠加姻缘叙事。

1. **查生年四化落六亲/夫妻宫** —— 取出生年干查十干四化曜表，定位四化星落宫；确认是否落夫妻宫或六亲宫。
   - 完成标准：能列出该命盘生年四化四星及其落宫，并标出夫妻宫所属象。
2. **套缘情诀推断姻缘聚散类型** —— 依二十字诀与目的十六字诀，判断属"缘尽情未了"等哪一态、此生姻缘课题为何。
   - 完成标准：能写出聚散四态之一 + 对应的人生课题表述。
3. **据夫妻宫四化定姻缘形态与早/晚婚** —— 禄（自由恋爱早发）/权（奉父母儿女命）/科（介绍认识）/忌（缘薄宜晚婚、初恋不宜结合）取义。
   - 完成标准：能给出夫妻宫四化对应的姻缘形态一句断语，并标注早婚/晚婚倾向。
4. **给顺势建议** —— 如忌在夫妻宜晚婚、初恋不宜急结；贪狼坐命宜配偶大五岁以上；结合"心有傲数之功"引导平衡。
   - 完成标准：建议具体、顺势（非逆势硬断），并注明非婚恋决策唯一依据。

## B（边界与诚实声明 · Boundary）

**反场景（不调用本技能）**：非姻缘/夫妻宫问题（财官、疾厄、寿元、学业等）不调用；一般四化读象交给 hua-ji / trinity。

**书中明确警告（必须守界）**：
- **ce05**：化科/桃花象 ≠ 外遇重婚。"主桃花，命带大桃花。并不等于三妻四妾，也并不等于红杏出墙。" 不可把异性缘夸大为出轨。
- **ce07**：红鸾星动 ≠ 必提亲论嫁。"皆为喜庆之星……但并非俗称【红鸾星动】，该年必有人提亲或论及婚嫁之事。" 婚姻和合不依红鸾论断。
- **ce04**：左右弼 ≠ 必二度姻缘。"古书云【左右在命夫，必主二度姻缘】。但未必如是说，食古不化、以讹传讹，莫此为甚！" 正确解为婚前感情困扰/三角，或对象曾婚丧偶，非必然再婚。

**作者盲点**：缘情诀/目的诀是钦天四化本派的叙事框架，将姻缘道德化、宿命化（"来还恩怨情仇"），属象征解释系统；作者立场鲜明、学派自抬，未与他派（三合/飞星）比较优劣边界。

**元边界（诚实声明）**：传统命理未经现代科学实证，四化垂象与人生吉凶缺乏可重复、可证伪证据，易落巴纳姆效应与确认偏差。本技能仅作**文化性象征解释与人生反思框架**，**不可作为婚恋、结婚/离婚等重大决策的唯一依据**。
