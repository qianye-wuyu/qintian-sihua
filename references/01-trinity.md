
## R — 原文

> "这门紫微斗数是由宫、象、星来构成主要内容。宫象星三合一是这门紫微斗数命理学的内容之精要。首重在宫象合一，便呈现吉凶的吉或者吉凶的凶；而后再配星；构成宫象星三合一的完整解译学。"
> ——《钦天四化紫微斗数基础》许铨仁，A02 四化象（约 127–135 行）

## I — 方法论骨架

本派读盘的总入口，是一套三步走的"宫象星三合一"结构：

1. **定宫位框架**：先确定所论事项对应哪一宫职（命、兄、夫、子、财、疾……十二宫皆可立太极，不必只以命宫为绝对中心），并留意其基本义与隐藏性含义（如夫妻宫以财帛为夫妻位，须参合）。宫位是整张盘的"坐标系统"。
2. **看四化象落宫，宫象合一出吉凶**：取出落入该宫的四化象——化禄、化权、化科、化忌，按"象依宫解"与"人、事、物三解"呈现吉或凶。**先求宫象合一，得出吉凶，** 此时已可论断，不必先配星。
3. **配星辰导气，完成三合一**：再列出该宫的星曜，按"物物一太极、阴阳五行推单星特质、双星碰撞、落宫影响"把抽象的象具体化到某一人、某一事、某一物，得到完整解译。

为什么"象（四化）"高于"星"？作者明言四化象是这门命理学的"灵魂、精髓、用神"——吉凶由天干气化飞渡使星辰质变而来，是"天垂象示吉凶"的垂象；星曜只是把象"导气"到具体人事的工具。故次第必须是"宫象合一 → 配星"，而非三合派以星曜庙旺为主。任何专项论断（财官、六亲、疾厄）都套用这套三步结构，是后续所有框架的地基。

## A1 — 书中的应用

**案例（c01 马英九命盘 — 化科带大桃花）**

- **问题**：如何用"宫象星三合一"读一张命盘？
- **怎么用**：①宫：命宫；②象：命宫有化科象，宫象合一即得"风度佳、语言举止斯文，能获得普天下女士的青睐"（科主科名贵人、桃花、风度）；③配星：太阴星在命宫，太阴为女性星、男士得女人之缘与助，把"科"的桃花象导气到具体——主桃花，命带大桃花。
- **结论**：宫（命宫）+ 象（化科）→ 宫象合一出"得女性青睐"；再配星（太阴）→ 落为"命带大桃花"。三合一成立。
- **结果**：书中特别划界——"命带大桃花"不等于三妻四妾、不等于红杏出墙，只是比常人更易有异性机会；并影射其"醉卧美人膝，醒握天下权"。本例完整演示了"先宫象合一、而后配星"的次第，是三合一总纲的标准示范。

## A2 — 触发场景

**用户情境（3 条）**
1. 拿到一张命盘不知从何下手，需要一套可操作的读盘总框架。
2. 问"怎么读紫微斗数""紫微斗数怎么入门"，想先建立方法论骨架再细学。
3. 已会排盘，但不懂宫、象、星三者如何配合、为什么"象"比"星"重要。

**语言信号**
"怎么看这张盘""宫象星怎么解""紫微斗数怎么入门""宫位和四化怎么配合""读盘先从哪里开始""read a ziwei chart / how to read this chart"。

**与相邻 skill 区分**
本 skill 是**总纲 / 入口**：只教"宫象星三合一"次第与为什么象为用神，不展开具体操作。具体读法交给专项 skill——立太极/中太极交给 `qintian-sihua-taiji`、读生年四化（体）交给 `qintian-sihua-natal`、飞宫（用）交给 `qintian-sihua-flying`、自化与时间应数交给 `qintian-sihua-self-transform`、逐宫解象交给 `qintian-sihua-by-palace`、化忌细解交给 `qintian-sihua-hua-ji`、双象组合交给 `qintian-sihua-dual-symbol`、星辰研究法交给 `qintian-sihua-star-study`。本 skill 是所有读象 skill 的地基。

## E — 可执行步骤

**步骤 1：定所论事项的宫位框架**
- 操作：明确用户所问（财、官、婚、疾、六亲…）对应哪一宫职；列出该宫基本义 + 隐藏性含义；可用"立太极"把该宫当中心（不必只取命宫）。
- 完成标准：能一句话说清"我是以哪一宫为分析中心、它管什么事"，并写明其基本义与隐藏义。

**步骤 2：看落入该宫的四化象 → 宫象合一呈现吉凶**
- 操作：取出该宫的四化象（生年四化为体、飞宫/自化为用），按"象依宫解"与"人、事、物三解"判定吉或凶。**先只做宫象合一，不急着配星。**
- 完成标准：能给出"宫+象"层面的吉凶判断（如"禄在兄弟宫→我与手足情深、借兄弟之力财禄显彰"），且未把星曜当唯一依据。

**步骤 3：配星辰导气，把象具体化**
- 操作：列出该宫主星/辅星，按"物物一太极 → 阴阳五行推单星特质 → 双星碰撞 → 落宫影响"把象落到具体人、事、物。
- 完成标准：能把抽象吉凶导气到某一具体人事（如"化科在命 + 太阴在命 → 命带大桃花"），星性描述有阴阳五行依据而非空想。

**步骤 4：得完整解译**
- 操作：宫+象+星三者合参，给出完整吉凶与人事指向；必要时提示体用之分（生年=先天定数、飞宫自化=后天变数）与时间应数（自化重心在大运/流年）。
- 完成标准：输出一句可验证的"宫象星三合一"结论，且标注吉凶来源（象）与具体化（星），不遗漏体用与时间维度。

## B — 边界

**反场景（不调用）**
- 纯信息查询：只问某星曜含义、只查十天干四化曜表，不需要"宫象星合一"的解译流程。
- 仅需排盘：用户只要排出命盘、不要求解读，本总纲不参与。
- 已确定专项读法：如用户明确只要"读生年四化""看飞宫"，应直接转对应 skill，不必从总纲重讲。

**书中明确警告（ce08：重星轻象、只论庙旺忽略四化）**
> "首重在宫象合一……而后再配星……四化象就是……灵魂、精髓之所在、是用神。"（A02，127–135 行）
失败模式：沿用三合派只论星曜庙旺利陷、以星曜组合直接断吉凶，忽略生年/飞宫/自化四化体系，把"星"抬到高于四化，违背"首重宫象合一、而后配星"的次第，使宫象星三合一失衡。只要论断不提四化象、只用星曜组合断吉凶，即是错误读法。

**作者盲点（学派自抬）**
作者为钦天四化流派传人，立场鲜明：把四化象抬为"灵魂/用神"，并明确贬低其他读法（称坊间紫微斗数书"东拼西凑、以讹传讹"）。文中未正面比较三合派、飞星派等的方法论差异，读者无从得知本派与他派在论断上的优劣边界，存在"学派自抬"的盲区。使用本 skill 时，应把本派立场当作一种流派方法，而非唯一真理。

**元边界（方法论诚实声明）**
钦天四化紫微斗数属于传统命理/象征解释系统，源于古代术数，未经现代科学实证。其"天干气化飞渡使星辰质变""物物一太极""命运可由出生时空垂象推知"均为未被证伪、亦未被证实的假设；"同盘不同命"难以在本体系内圆融解释，解象有极大的主观诠释空间（易落入巴纳姆效应与确认偏差）。因此，**本 skill 只应作为文化性的象征解释系统与人生命运的反思框架，不宜作为婚姻、创业、健康等重大决策的唯一依据。** 重大决策请结合现实信息与专业意见。
