
# 读飞宫四化（用）— 静动合参

## R · 出处与方法根基

> f04（A02 四化象）：
> "研究任何一个宫职，宫象星合一是不够的，还要从这个宫职的左下方的宫干化出去的化禄、化权、化科、化忌做解释象。则研究任何一个宫职要静动合参对这个宫职才有一个完整而深入的认识。"

飞宫四化属于「用」——代表后天变数、运的走势（体用之分见 p09：生年四化为体／飞宫与自化为用）。它把本派的「宫象星三合一」从静态推到动态：光看本宫星象只是"静"，加上宫干飞化才是"动"，动静合参才完整。

## I · 操作心法（论断任一宫职分两步）

1. **静态认识（本宫星象 · 宫象星合一）**：先看所研究宫职里有什么星、有什么象（生年四化落本宫、本宫自化等），按宫象星三合一得出一个基础认识（吉/凶、人事物轮廓）。这一步是地基，但不完整。
2. **动态认识（宫干飞化 · 解释象）**：从所研究宫职「左下方」的宫干飞出四化——化禄、化权、化科、化忌——看这四象分别飞到哪个宫位，依落宫做"解释象"，补足静态认识的不足。
3. **动静合参**：把第①步的静态结论与第②步的动态飞化并列。作者原话："一动就有吉凶"——飞出去的象落何宫，即在该宫产生吉凶垂象。
4. **应期功能**：飞宫四化是断"何年何月发生"的关键手法。某宫的运怎么走、何时发动，主要靠这一宫飞出去的象落点在哪一大运/流年宫来定（但须结合 ce09：自化才是用神中的用神、时间应数的重心，飞宫不可独占应期判断）。

一句话：任一宫职，宫象星合一不够，还要从左下宫干飞四化做解释象——静动合参，方得完整而深入的认识。

## A1 · 书中示范（壬干夫妻宫飞宫例 · c05）

- **问题**：研究"夫妻宫"——想论断婚姻何时发动、能否白首。
- **用法（动态认识）**：夫妻宫左下方有个天干，假设是「壬」干；从壬干飞出——天梁化禄、紫微化权、左辅化科、武曲化忌——看这四象各自"跑到哪个宫位"，再依落宫做解释象。
  > c05 原引："夫妻宫的左下方有个天干，比如假设是壬，从壬飞出来的天梁化禄，紫微化权，左辅化科，武曲化忌看跑到那个宫位，你去做解释象。这就是所谓的动态的认识。"
- **结论**：研究任何宫职，光有本宫星象（静态）不够，必须加宫干飞四化（动态）做解释象；二者合参才完整，一动即有吉凶。此例示范了"选定宫职→取左下宫干→飞四化→按落宫解象"的完整链路。

## A2 · 适用情境与识别信号

**情境**：
- 想看"某宫的运"怎么走（如财帛宫这十年财运走势、官禄宫事业起伏）。
- 要断应期——某件事"何年何月发生"（结婚、创业、升迁、破财的发动时点）。
- 用户直接问"飞宫四化怎么飞""从宫干怎么飞""怎么从宫干看运势走势"。

**信号（命中本 skill 的问法）**：
- "飞宫四化""从宫干飞""宫干飞出来"
- "怎么看运势走势""某宫的运怎么走"
- "断应期""什么时候会发生"

**与相邻 skill 的区分**：
- 本 skill 读**动态用象**（宫干飞化 → 运的走势、应期）。
- `qintian-sihua-natal` 读**静态体象**（生年四化 = 先天定数、此生格局），只看本命格、不飞宫时用它。
- `qintian-sihua-self-transform` 读**自化/视同自化**（用神中的用神、今生造化、时间应数的重心）；断应期时二者互为补充，飞宫不可取代自化。
- 三者都建立在 `qintian-sihua-trinity`（宫象星三合一）之上——先立太极、先宫象合一，再谈飞化。

## E · 执行步骤与完成标准

**步骤**：
1. **选定研究宫职**：明确要判断的是哪一宫（夫妻/财帛/官禄/命/子女…），以其立太极（任意宫皆可为中心，见 p01）。
2. **取其宫干**：找到该宫**左下方**的宫干（即该宫"气"飞出的源头，注意不是命宫干，是研究宫自身的左下宫干）。
3. **飞四化**：依十天干四化曜表，从该宫干飞出化禄、化权、化科、化忌四象，标出每象落于何宫。
4. **按落宫解象（静动合参）**：对每一落点用"象依宫解 + 六亲视同命宫 + 人事物三解"解释；把第①步的静态本宫象与第②③④步的动态飞化并列，得出吉凶与走势结论，并指出应期落点（何大运/流年）。

**完成标准（每条可核验）**：
- [ ] 已明确"研究宫职"并立为太极，未错用命宫干代替其左下宫干。
- [ ] 四象（禄权科忌）已全数飞出并标出各自落宫，无遗漏。
- [ ] 每个落点已按"象依宫解"给出人/事/物解释，并区分六亲宫换主语。
- [ ] 已做动静合参——静态本宫象与动态飞化并列，结论非单看一边。
- [ ] 若用于断应期，已注明需与自化（qintian-sihua-self-transform）合参，未把飞宫当唯一应期依据（避 ce09）。

## B · 边界与反模式

**反场景（本 skill 不适用）**：
- 仅需看"先天格"——只想定此生富贵贫贱之格、不关心运的走势时，用 `qintian-sihua-natal` 读生年四化即可，不必飞宫。
- 纯排盘/只列星曜庙旺不谈四化——属 ce08（重星轻象），不在本 skill 范围。

**书中明确警告（ce09 · 飞宫/自化混淆）**：
> "自化象和视同自化象都是象之用……自化的重心在时间的观念，故其解释重心在大运的宫位、或流年宫位。……自化象和视同自化象是用神中的用神。"

失败模式：只从宫干飞宫四化找"哪年哪月发生"，忽略自化/视同自化才是"用神中的用神"、其解释重心在大运/流年应数，致**应期错判或漏读变数**。机制是把飞宫（动态认识、运的走势）与自化（用神中的用神、今生造化、时间应数）混为一谈。

**作者立场盲点**：
- 作者为本派传人，把四化象抬为"灵魂/用神"，并明确贬低他派（称坊间书"东拼西凑、以讹传讹"），未正面比较三合派/飞星派差异，存在学派自抬盲区。
- 飞宫学"八大原则"（A08–A09）原文对应页为空页未读到，本 skill 只取 A02 总法（静动合参），不杜撰缺失的八条细则。

**元边界（诚实声明）**：
- 本书属传统术数/玄学体系，源流为古代术数，**未经现代科学实证**。其世界观（物物一太极、气化飞渡）属前现代宇宙观。
- 四化垂象与人生吉凶之间缺乏可重复、可证伪的经验证据；"同盘不同命"难在本体系内圆融解释；解象主观诠释空间大，易落巴纳姆效应与确认偏差。
- 最稳妥立场：将其视为一套**文化性象征解释系统**与**人生反思框架**，不宜作为婚姻、创业、健康等重大决策的**唯一**依据。
