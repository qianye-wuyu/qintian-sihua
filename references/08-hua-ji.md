
# 化忌象解读法（收藏 / 收束 / 管束 / 亏欠 · 六内六外财官得失 · 平衡学）

## R — 来源（Reference）

> f09 原文引述（化忌多重情境）：
> 「化忌在不同的场合解释为不同的意思……化忌主收藏是指财的得失吉凶论，条件是财帛化忌入六内宫。收束是指桃花，人位代表桃花收束了。人位忌入人位，这里的忌入解释为管束。」
> —— A06-A07 化忌象

化忌并非一见即凶，而是随「人事物条件」切换解释的核心决策对象。

## I — 解释（Interpretation）

化忌非一见即凶，须按「忌落宫的人事物属性 + 是否入六内六外 / 是否人位对人位 / 是否六亲宫」切换解释。决策树：

1. **收藏 / 冬藏（吉）**：财帛宫飞化忌「入六内宫」＝得财、收藏冬藏，主得财论（大好特好）。
2. **收束**：桃花星（贪狼等）自化忌＝桃花因自我造化而收束、懂得拒绝诱惑。
3. **管束**：人位（六亲宫）忌入人位＝前宫之人喜欢管束后宫之人（如夫妻宫忌入命宫＝配偶管束我）。
4. **亏欠**：化忌入六亲宫＝对该亲潜意识亏欠感、易溺爱（忌在子女主亏欠子女）。
5. **不顺 / 缘薄**：入迁移等非人位宫＝主无缘、缘薄、人生观价值观有差距（非必邢剋）。

**财官得失的总纲**：财帛宫飞忌入「六内宫」＝得财吉，宜创业 / 投资；入「六外宫」＝破财凶，宜保守上班、以时间换空间。这是平衡学的「顺势而为」，切忌见忌如见鬼。

## A1 — 书中应用（Applications）

**案例一：37 岁金融机构男士问创业（化忌入六内得财）｜ c08**
- 问题：可否辞工作出来创业？
- 用法：看「这十年财帛宫」（非官禄宫）；该宫宫干甲使太阳化忌飞入疾厄宫（六内宫）。
- 结论：化忌入六内＝收藏得财，适合创业；若入六外宫则不该辞工作、更不该创业。化忌非凶，入六内反主吉。

**案例二：夫妻宫化忌入命宫（管束）｜ c10**
- 问题：夫妻关系如何？
- 用法：夫妻宫（癸干）使贪狼化忌，恰落命宫；夫妻宫是人位、命宫也是人位 → 人位忌入人位。
- 结论：解作「我的配偶喜欢管束我」，不取财运或钻牛角尖义；同理入子女＝配偶管束子女。

## A2 — 激活（Activation）

**情境**：解化忌象 / 问六内六外财官得失 / 问忌在夫妻宫或子女宫。
**信号**：「化忌怎么解」「见忌是不是凶」「六内六外怎么分」「忌在财帛」「忌在子女」「化忌入某宫主什么」。
**区分**：
- 本 skill 专解「化忌」单象的多重情境与财官得失；
- `qintian-sihua-dual-symbol` 解双象组合（如禄忌双忌论大凶）；
- `qintian-sihua-by-palace` 解一般落宫（象依宫解的通用口径，不强调化忌的特殊切换）。

## E — 执行（Execution）

1. **定忌落宫的人事物属性**：取化忌所在宫，先定其「人 / 事 / 物」三解属性（依 `qintian-sihua-by-palace`）。
   - 完成标准：能说明该宫基本义与当前象属人、事、物哪一面。
2. **判落宫分组**：①财帛宫飞忌 → 入六内宫 or 六外宫（财官得失）；②是否人位忌入人位（管束）；③是否入六亲宫（亏欠）。
   - 完成标准：明确标注落点属「六内得财 / 六外破财 / 人位对人位 / 六亲宫」之一类。
3. **按对应义取解释**：六内→收藏得财；桃花星自化→收束；人位对人位→管束；六亲宫→亏欠；迁移等非人位→缘薄不顺。
   - 完成标准：解释与步骤 2 判定类别一一对应，不混用凶义。
4. **给顺势而为的建议**：依象给决策（得财宜创业、破财宜上班；忌在财帛守财不牢宜置产保险；忌在命 / 官禄宜上班，硬创业只做冷门偏门现金生意）。
   - 完成标准：建议承接象义，体现「平衡学 · 顺势而为」，不逆势操作。

## B — 边界（Boundary）

**反场景（正被本 skill 纠正）**：一见化忌即断凶、不查落宫的草率读法。本 skill 存在的意义就是纠正「忌＝凶」的字面偷换。

**书中明确警告**：
- `ce01` 见忌如见鬼：财帛飞忌入六内是大好特好，却误判破财。
- `ce02` 忌冲即邢剋：忌冲只是「缘薄 / 价值观差距」，非必刑克，需「心有傲数之功」平衡。
- `ce10` 逆势硬创业：忌在命 / 官禄即断无事业，或逆势创主流长期事业致倒闭；应上班为宜、硬创业只做冷门偏门现金生意。

**作者盲点**：本书属传统术数，将现代职业（金融、直销、美容等）套入星曜事物论，且用「物理学质能转化」类比天干气化飞渡，属现代话语借喻而非实证；作者为该流派传人，立场鲜明贬低他派，六内六外具体宫名未列、河洛理数未展开。

**元边界（诚实声明）**：紫微斗数为传统命理 / 象征解释系统，未经现代科学实证，同盘不同命难圆融。本 skill 仅作文化性反思框架，不作重大财务、婚姻、健康决策的唯一依据。
