
# 双象组合解释法（A09）

## R — 来源（Reference）

> 来源 f11 · A09 双象的解释（原书原文引用，≤150字）：
> 「象本就缘盖天下之理。象要站在人、事、物来做解说。禄权：人（二度姻缘，泛水桃花）；事物（多元化事业、跨行跨业）。禄忌：事物，起伏大、变化大、周转大，往往双忌论大凶。」

## I — 方法（Instruction）

两象并看比单象更细：单象只给笼统倾向，同宫/相关的两象合参能锁定更精准的人、事、物含义。

**六组双象组合义（按人 / 事 / 物查）：**

| 双象 | 人（人缘/性格） | 事 / 物（事件/行业/财物） |
|---|---|---|
| 禄权 | 二度姻缘、泛水桃花（不专情） | 多元化事业、跨行跨业、财官皆美 |
| 禄科 | 良性桃花、文教之交 | 文教之财、文教相关事业 |
| 权科 | 专业技术、才艺；一显一隐、一先一后 | 象二数一，专技立身 |
| 禄忌 | — | 起伏大、变化大、周转大（人生荡秋千）；往往双忌论大凶 |
| 权忌 | 来的急、去得快；婚后谈恋爱；结束一刀两断 | 无文凭有技术；须防交通意外 |
| 科忌 | 藕断丝连、纠缠是非、拖拖拉拉 | 上班格，教育/科技/服务业 |

**操作步骤：**
1. 抓出同宫或相关的两象（如本宫既有生年禄又有飞宫权）。
2. 按「人 / 事 / 物」分别查上表对应的双象组合义。
3. 结合落宫（象依宫解）与宫职人事物三解，得出比单象更精准的人事物结论。

## A1 — 书中应用（Application）

**案例 c14 · 武曲贪狼坐命走己运横发（禄权双象）**

- **问题**：武曲贪狼坐命者问「某十年财运与事业如何？」
- **用法**：该大运命宫宫干为己，使武曲贪狼化禄、化权入本命命宫，同宫构成「禄权」双象。查组合义 → 禄权主「财官皆美、很多」。
- **结论**：此十年横发（仅发约三年）、财官大好、投资投机皆可；但横发后宜守，且宜部分回馈社会（孤儿院、慈济等）以保福泽寿元（p28/p30 + c14）。

## A2 — 触发与区分（Activation）

**适用情境：**
- 命盘某宫出现两个四化象，用户问「这两个象一起怎么解」。
- 用户直接问双象组合义：禄权、禄科、权科、禄忌、权忌、科忌。
- 出现「双忌」局面，问「双忌论大凶」是否成立。

**信号词：** 「双象」「禄权」「禄忌」「权忌」「科忌」「双忌论大凶」「二度姻缘」「藕断丝连」。

**与相邻 skill 的区分：**
- 本 skill 解**两象组合**义；单颗化忌的解读与落宫（收藏/管束/亏欠/六内六外）交 `qintian-sihua-hua-ji`。
- 单象落宫解（象依宫解、六亲视同命宫、人事物三解）交 `qintian-sihua-by-palace`。
- 夫妻宫「二度姻缘」需区分：本 skill 指禄权双象之「二度姻缘/泛水桃花」；而 `qintian-sihua-laiyin`（来因观）论夫妻宫化忌/生年四化的姻缘形态（如忌主初恋不宜结合），二者成因不同，勿混。

## E — 完成标准（Execution Checklist）

执行完毕须满足：

1. **抓象**：已明确列出同宫/相关的两象，且确认是两象而非单象（若仅一象，应转 `qintian-sihua-by-palace` / `qintian-sihua-hua-ji`）。
2. **查义**：已按「人 / 事 / 物」三方查得对应双象组合义（参照 I 表），未漏任何一方。
3. **结论**：已结合落宫与宫职人事物三解，给出比单象更精准的人事物结论；若构成双忌，已明确是否「论大凶」并说明条件。

## B — 边界与诚实声明（Boundary）

**反场景（不强行组合）：**
- 单象已能定论时不强行凑双象；本 skill 只在确有两象并现、且组合义比单象更细时启用。

**书中明确警告（ce04）：**
- 左辅/右弼入命宫或夫妻宫，古书断「必主二度姻缘」是**食古不化、以讹传讹**。其正解与禄权双象的「二度姻缘」不同：左右主「婚前感情困扰/三角死角、对象曾婚丧偶而再婚」，非必然二度姻缘。二者勿混淆。

**作者盲点（学派自抬）：**
- 作者为本派传人，将四化象抬为「灵魂/用神」，并贬低他派读法；未正面比较三合派、飞星派在双象论断上的优劣边界。

**元边界（方法论诚实）：**
- 紫微斗数属传统命理/玄学体系，源自古代术数，未经现代科学实证。本 skill 是一套**文化性象征解释系统**与人生反思框架，不可作为婚姻、创业、健康等重大人生决策的唯一依据。
