
# 断长寿诀（禄科入命迁父疾）

## R —— 书中原话（Reference）

> 「生年禄、生年科落在命迁父疾就是长寿的命格。因为生年禄，含有解恶制化。生年科，本身解恶制化。所谓长寿就是比平均寿元多一成以上。」（A05 化科象／断长寿诀，f12）

## I —— 自己的话（Interpretation）

以生年四化定寿元格局的口诀，共五条：

1. **长寿格定义**：生年禄 **或** 生年科落入**命宫、迁移、父母、疾厄**四宫之一，即为长寿格。此四宫主健康、寿元（p14 / p15）。
2. **原理**：禄与科皆具「解厄制化」之功，能化解凶恶、护持健康，故落这四宫便成长寿架构（p14）。
3. **长寿基准**：作者以「比平均寿元多一成以上」为长寿。书中举例：台湾平均男士 73、女士 79；则长寿约男士 80 以上、女士 87 岁以上（c02）。
4. **禄科最好不同宫**：生年禄与生年科最好分散于不同宫，长寿程度更高；**禄科同宫也是长寿，但可能仅达「一成」的较低限度**（p16）。
5. **量化可浮动**：一成是下限，并非封顶——有人「不止一成」，如蒋宋美龄享寿 106 岁，较平均女士多三成（c02）。

口诀本质：用「生年禄/科是否入命迁父疾」这一静态的体象（生年四化＝体，见 qintian-sihua-natal），快速判定一张命盘是否具长寿架构。

## A1 —— 书中应用案例（Application）

**案例：蒋宋美龄 106 岁 —— 断长寿诀印证**（依据 c02 / p15）

- **问题**：如何验证「生年禄科入命迁父疾为长寿格」这条口诀？
- **用法**：
  1. 取出生年干，定生年禄、生年科落宫（生年四化＝体，须先由 qintian-sihua-natal 读出）。
  2. 查该禄/科是否落入命、迁、父、疾四宫之一——若入，依口诀即判长寿格。
  3. 套量化标准：以当时平均女士 79 岁为基，多一成以上（87 岁以上）即长寿；本例更超出，达 106 岁。
- **结论**：蒋宋美龄享寿 106 岁，较平均女士多三成，是「生年禄科落命迁父疾为长寿格」的典型例证，印证断长寿诀有效。注意：书以此作**口诀有效性的佐证**，非教读者反推其落宫。

## A2 —— 调用情境与边界（Activation）

**触发情境（3 条）**
1. 问「怎么看寿命格局」「长寿格怎么断」「断寿元」「是不是长寿的命」；
2. 问「生年禄/生年科落在哪宫主长寿」「禄科主不主长寿」；
3. 已读出生年四化（qintian-sihua-natal），想进一步判其是否构成长寿架构。

**语言信号**
- 「怎么看寿命」「长寿格」「生年禄科」「断寿元」「禄科入哪宫主长寿」

**与相邻 skill 的区分**
- 本 skill 仅给**寿元格局口诀**（禄科入命迁父疾）；
- `qintian-sihua-natal`（读生年四化）是前置依赖——须先读出禄/科落宫，本 skill 才用得上；
- `qintian-sihua-hidden-palace`（宫职隐藏性含义）涉及**奴仆宫＝绝情宫＝论断寿元的关键宫**，与本书「禄科入四宫」是两条互补的寿元视角，复杂寿元须合参；
- 本 skill **不管**富贵贫贱、财官、六亲等其余格局。

## E —— 执行步骤（Execution）

1. **查生年禄/科落宫**：依出生年干取生年四化（体），定位生年禄、生年科分别落在哪一宫（前置见 qintian-sihua-natal）。
   - *完成标准*：已列出生年禄落宫、生年科落宫，落宫来自十干四化曜表，非臆测。

2. **判长寿格**：若生年禄**或**生年科落入命宫、迁移、父母、疾厄四宫之一，即判为长寿格（禄科具解厄制化之功）。
   - *完成标准*：已明确「落入哪宫 → 是否命中四宫之一 → 长寿格／非长寿格」的结论。

3. **看禄科是否同宫**：若禄、科同落一宫，结论须注明「亦长寿，但可能仅约一成（较低限度）」；若分散不同宫，长寿程度更高。
   - *完成标准*：已区分同宫/不同宫，并据 p16 给出程度提示。

4. **给寿元格局结论**：以「平均寿元＋一成以上为长寿」为基准，给出口诀层面的寿元格局判断（如「长寿架构成立，程度高于一成」），并提示本书另以奴仆宫（绝情宫）参合寿元。
   - *完成标准*：结论仅限寿元格局口诀，未越界做全命论断或具体应期。

## B —— 边界与诚实声明（Boundary）

**反场景（不调用）**
- 问非寿元问题（富贵、财官、姻缘、六亲、事业等）——交给对应 skill（natal / flying / dual-symbol 等）；
- 仅要排盘或读生年四化落宫——交给 qintian-sihua-natal；
- 要复杂寿元论断（含奴仆宫绝情宫、大运流年应数）——须合参 qintian-sihua-hidden-palace，本 skill 只给静态口诀。

**书中警告（不杜撰）**
- 仅限寿元格局：本口诀是「断命诀」之一，只判寿元架构，**非全命论断**。书中明言边界「仅限寿元格局，非全命论断」（verified.md #10）。
- 禄科同宫程度较低：同宫也长寿，但依 p16 可能仅约一成，不可夸大。
- 奴仆宫（绝情宫）为另一寿元关键宫：本书寿元视角不仅禄科四宫，亦含奴仆宫（p06），本 skill 不覆盖，须交 hidden-palace。

**作者盲点**
- 作者为本派（钦天四化）传人，立场鲜明地把四化象抬为「灵魂/用神」，将「禄科解厄制化、主长寿架构」作为特定口诀，未正面比较他派寿元论断差异，存在学派自抬倾向。

**元边界**
- 本体系属传统命理/玄学，源流为古代术数，未经现代科学实证；命盘垂象与寿命之间缺乏可重复、可证伪的经验证据，「同盘不同命」难以圆融解释。寿元判断不可作医疗或健康依据，应视为文化性象征解释与人生反思框架。
