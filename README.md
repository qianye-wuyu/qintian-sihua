# 钦天四化紫微斗数排盘解读器（qintian-sihua）

一个把许铨仁《钦天四化紫微斗数基础》蒸馏成可执行方法的 **WorkBuddy skill**。

你给它一张**钦天四化风格排盘（文字版最优，图片仅作辅助）+ 出生年月日时性别**，它先「读盘 + 双轨校验」，再按你想看的方面（事业 / 婚姻 / 财运 / 健康 / 子女 / 全盘…），用书中 13 块方法论给出结构化、可追溯的解读。

> 方法论来源：许铨仁《钦天四化紫微斗数基础》。经 [仓颉技能工坊（cangjie-skill）](https://github.com/) 6 阶段蒸馏流程（Adler 理解 → 并行抽取 → 三重验证 → RIA++ 构造 → Zettelkasten 链接 → 压测交付）凝练为 13 个方法论主题，作为 `references/` 按需加载的知识库。

> **⚠️⚠️⚠️ 重要警告（开始使用前务必先读）⚠️⚠️⚠️**
>
> 下面两条如果忽略，本 skill 的解读会直接失准，或把你的盘读错。请务必先读完再使用。

### ⚠️ 警告一：排盘请务必使用「四化」方法

本 skill 的方法论建立在**钦天四化派**之上，核心依赖**生年四化（禄 / 权 / 科 / 忌）、飞宫四化、自化**这些信息。

- 如果你用的排盘软件选了**三合派**（只标星曜的庙旺平陷、不标四化），本 skill 将无法正确解读，结论会完全失准。
- **正确做法**：在任何排盘软件里，把排盘模式设为「**四化**」或「**飞星**」，不要用「三合」。排出的盘必须清晰标注每宫的**生年四化（禄 / 权 / 科 / 忌落在哪一宫、哪一星）**——这是钦天四化派最核心的信息。

### ⚠️ 警告二：截图图片会被大模型识别错误，强烈建议用「文字版排盘」

**实测发现：当前 AI 大模型在读取紫微斗数排盘截图时，会稳定地把宫名读串，甚至会因没解析出盘中横竖格线，把整宫的星曜错误归到相邻宫（网格布局错位）。** 这不是多试几次就能解决的模型硬伤，而是「密集中文小字 + 形近字（官/交、禄/友、辰/酉、未/午）+ 截图压缩」共同导致的识别失败。

后果可能很严重：

- 轻则把「禄在交友宫」误读成「禄在官禄宫」——两者论断天差地别；
- 重则把命宫的星曜错配到兄弟宫，产出一张「高信心、内自洽、但整体错位」的假盘，你不核对就容易信以为真。

**强烈建议：不要直接发截图，改用排盘软件导出的「文字版排盘」（见下方「排盘建议」）。文字版零误读，是本 skill 最可靠的输入。**

如果只能发图，skill 会强制让你逐项确认读盘结果，但仍有风险——**永远以你确认/手填的文字盘为准，不要轻信纯图读结果。**

## 💡 排盘建议：用「文墨天机」软件导出文字版

为了让输入最稳妥、读取零误差，推荐用 **文墨天机** 这款排盘软件，按以下步骤拿到文字版排盘：

1. **排盘**：在文墨天机里，把排盘模式设为「**四化盘**」，输入出生年月日时 + 性别，排出你的命盘。
2. **找功能**：排好盘后，点击界面里的「**常用功能**」。
3. **复制文字版**：在常用功能里找到「**AI 分析**」入口，点进去即可**一键复制文字版排盘**。
4. **删掉顶部 AI 提示词**：复制出来的文本，最上端会带一段 AI 提示词（类似「你现在是资深的国学易经术数领域专家，请详细分析……」）。**请把这段提示词整段删掉，只保留从「文墨天机紫微斗数命盘」开始的排盘内容**，然后粘贴给本 skill。

> 这样你得到的就是一份结构完整、零误读的文字盘，可直接作为本 skill 的权威输入，无需再走图片确认流程。

## 它能做什么 / 有什么用

**能**

- 接收你提供的钦天四化排盘（**文字版最优，图片仅作辅助**），解析十二宫、宫干、主星、生年四化、自化。
- 用出生年干独立校验生年四化，与你的文字盘互证（**双轨校验**），防止盘本身或识别出错。
- 按你想看的方面，调用对应方法论，给出**结构化、可追溯**的解读（每步标注所用方法，如「[立太极]」「[落宫解象]」「[化忌·六内六外]」）。

**不能**

- **不含排盘引擎**：不替你排出一张全新的盘。完整十二宫 / 主星以**你确认/手填的文字盘为准**。
- 不替代专业帮助：传统命理 / 象征解释系统，未经科学实证，**不作为婚姻、创业、健康、医疗等重大决策的唯一依据**。

## 怎么用（对话式）

### 情形一：直接给文字版排盘（★ 最推荐，零误读）

把你从文墨天机复制、并删去顶部提示词的文字盘直接粘贴过来（可同时附上生辰）。skill 收到后做一次年干校验即进入解读。例如：

```
文墨天机紫微斗数命盘
├基本信息
│ ├性别 : 男
│ ├农历时间 : 乙酉年四月廿二日辰时
│ ├节气四柱 : 乙酉 辛巳 癸丑 丙辰
│ └命盘类型 : 四化盘
├命盘十二宫
│ ├命宫[己丑] 天相[庙]
│ ├兄弟宫[戊子] 巨门[旺]
│ ├父母宫[戊寅] 天同[利],天梁[庙][生年权]
│ └ …（其余各宫补全）
```

### 情形二：首句就是一张图（需逐项确认，有风险）

1. **发图**：直接把钦天四化排盘截图作为对话第一条消息发过来（可同时附生辰）。
2. **AI 识图 + 诚实确认**：skill 会先读图，然后**强制**给你两张东西——
   - 一张【识图确认表】：逐行列出它「识别到」的十二宫 / 宫干 / 主星 / 四化，并标注**识别信心**；明确提示「宫名小字易读错，请逐项核对」。
   - 一张【可编辑文字盘】：12 行模板，你可直接手改。
3. **你确认或手改**：若识别有误，直接在文字盘里改正发回；若无误，回复「确认」。**未确认 skill 绝不进入解读。**
4. **（若有生辰）双轨校验**：用出生年干独立校验生年四化，标 ✓ / ⚠。
5. **出解读**：确认后，skill 问你想看哪方面，再调方法论给结构化解读。

> 为什么图片要这么麻烦：正是警告二说的——AI 读截图会读错宫名 / 宫位，所以必须你确认。能用文字版就别用图。

### 情形三：发图 + 生辰同发

同情形二，但第 4 步双轨校验会在识图后即时完成。

### 示例问答

> **用户**：（粘贴文字版排盘）男，2005-05-29 辰时。
> **解读器**：收到文字盘，以它为权威输入。用品年干 (乙) 校验生年四化——乙干：天机禄 / 天梁权 / 紫微科 / 太阴忌，与盘内标注一致 ✓。确认后问「想看哪方面？」
> **用户**：看事业和财运。
> **解读器**：调 03-natal / 04-flying / 08-hua-ji 等，给出结构化解读……

## 边界与诚实声明

- 本体系是**传统命理 / 象征解释系统**，未经现代科学实证。解读仅供**参考与人生反思**，**不作为婚姻、创业、健康、医疗等重大决策的唯一依据**。
- 原书未展开的四块内容——来因宫取法、河洛理数、飞宫八大原则、六内 / 六外宫名——已按许铨仁理论联网多方查证、交叉验证后补全，见 `references/verified-supplements.md`（含来源分级：A 级原书原文 / B 级课程录音整理 / C 级旁证，与可信度标注）。超出该范围的内容仍不杜撰。
- 排盘图片 OCR 可能出错——这正是本 skill 坚持「双轨校验 + 逐条请用户确认」的原因。请务必认真核对读盘结果再进入解读。

## 安装方法

本目录即一个自包含的 skill，把 `qintian-sihua/` 整个文件夹放到 WorkBuddy 的 skills 目录即可：

```bash
# 方式一：clone 后复制
git clone <your-repo-url> /tmp/qintian-sihua
cp -r /tmp/qintian-sihua ~/.workbuddy/skills/qintian-sihua

# 方式二：直接把文件夹放进 skills 目录
# 把 qintian-sihua/ 整个文件夹放到 ~/.workbuddy/skills/ 下
```

目录结构需保持：

```
~/.workbuddy/skills/qintian-sihua/
├── SKILL.md                          # 前门：触发 + 读盘 + 路由 + 流程
├── README.md                         # 本文件
├── references/
│   ├── 01-trinity.md … 13-laiyin.md  # 13 篇方法论
│   ├── ten-gans-four-transform.md    # 十天干四化曜表（读盘/飞宫/自化必备）
│   ├── glossary.md                   # 术语表
│   ├── verified-supplements.md       # 许铨仁理论查证补全（来因/河洛/飞宫八大局/六内六外）
│   └── methodology-overview.md       # 方法论地图
└── assets/                           # 样例图等
```
